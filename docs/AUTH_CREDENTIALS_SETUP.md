## 1. Google OAuth 2.0 (Login with Google)

### Required Credentials:
- **Client ID**: Format `xxxxxx.apps.googleusercontent.com`
- **Client Secret**: Format `GOCSPX-xxxxxx`

### Hyperlink to Obtain Credentials:
👉 **[Google Cloud Console Credentials Dashboard](https://console.cloud.google.com/apis/credentials)**

### Setup Steps:
1. Open the [Google Cloud Console Credentials](https://console.cloud.google.com/apis/credentials).
2. Click **Create Credentials** ➔ select **OAuth client ID**.
3. Set **Application type** to `Web application`.
4. Enter **Name**: `NamoGPT Web Client`.
5. Under **Authorized JavaScript origins**, add:
   - `https://namogpt.onrender.com`
   - `https://douzzpvsfvvjlaiuwoce.supabase.co`
   - `http://localhost:5173` (Vite dev server default)
   - `http://localhost:3000` (production preview port)
6. Under **Authorized redirect URIs**, add:
   - `https://douzzpvsfvvjlaiuwoce.supabase.co/auth/v1/callback`
   *(Note: OAuth tokens are processed through Supabase callback and returned seamlessly to the frontend SPA).*
7. Click **Create** and copy your **Client ID** and **Client Secret**.
8. Go to your **[Supabase Google Provider Settings](https://supabase.com/dashboard/project/douzzpvsfvvjlaiuwoce/auth/providers)**.
9. Toggle Google to **Enabled**, paste the **Client ID** and **Client Secret**, and click **Save**.

## 2. GitHub OAuth (Login with GitHub)

### Required Credentials:
- **Client ID**: 20-character hexadecimal string
- **Client Secret**: 40-character hexadecimal string

### Hyperlink to Obtain Credentials:
👉 **[GitHub Developer Settings - OAuth Apps](https://github.com/settings/developers)**

### Setup Steps:
1. Open [GitHub Developer Settings - OAuth Apps](https://github.com/settings/developers).
2. Click **New OAuth App** (or **Register a new application**).
3. Fill out the application registration:
   - **Application name**: `NamoGPT`
   - **Homepage URL**: `https://namogpt.onrender.com`
   - **Application description**: `NamoGPT Cognitive Workspace & LiteLLM Smart Router`
   - **Authorization callback URL**:
     ```
     https://douzzpvsfvvjlaiuwoce.supabase.co/auth/v1/callback
     ```
4. Click **Register application**.
5. Copy the **Client ID**.
6. Click **Generate a new client secret** and copy the secret immediately.
7. Go to your **[Supabase GitHub Provider Settings](https://supabase.com/dashboard/project/douzzpvsfvvjlaiuwoce/auth/providers)**.
8. Toggle GitHub to **Enabled**, paste the **Client ID** and **Client Secret**, and click **Save**.

## 3. Apple Sign-In (Login with Apple)

### Required Credentials:
- **Services ID**: Reverse domain string (e.g., `com.namogpt.auth`)
- **Apple Team ID**: 10-character alphanumeric ID found in your Apple Developer Membership
- **Key ID**: 10-character ID from your Apple Sign in Key
- **Secret Key (.p8 file)**: Private cryptographic key generated by Apple

### Hyperlinks to Obtain Credentials:
👉 **[Apple Developer Portal - Identifiers & Service IDs](https://developer.apple.com/account/resources/identifiers/list/serviceId)**  
👉 **[Apple Developer Portal - Keys & Sign in with Apple](https://developer.apple.com/account/resources/authkeys/list)**  
👉 **[Apple Developer Membership Details (Find Team ID)](https://developer.apple.com/account#!/membership)**

### Setup Steps:
1. In [Apple Identifiers](https://developer.apple.com/account/resources/identifiers/list/serviceId), create a **Services ID** (e.g., `com.namogpt.auth`).
2. Enable **Sign in with Apple** on the Service ID and click **Configure**:
   - **Primary App ID**: Select your App ID.
   - **Domains and Subdomains**: `douzzpvsfvvjlaiuwoce.supabase.co`, `namogpt.onrender.com`.
   - **Return URLs**:
     ```
     https://douzzpvsfvvjlaiuwoce.supabase.co/auth/v1/callback
     ```
3. In [Apple Keys](https://developer.apple.com/account/resources/authkeys/list), create a new Key named `NamoGPT Sign in with Apple Key`, check **Sign in with Apple**, and click **Continue** ➔ **Register**.
4. Download the generated `.p8` key file and record the **Key ID**.
5. Go to your **[Supabase Apple Provider Settings](https://supabase.com/dashboard/project/douzzpvsfvvjlaiuwoce/auth/providers)**.
6. Toggle Apple to **Enabled**, enter your **Services ID**, **Team ID**, **Key ID**, and the contents of the `.p8` key file. Click **Save**.

## 4. Real-Time Email OTP / Magic Link Authentication

NamoGPT implements **dual-path email authentication**:
1. **Frontend Direct Supabase Auth OTP**: Instant magic link or 6-digit OTP code directly managed by Supabase Auth.
2. **Backend Hardened SMTP / Resend Mailer**: In-process cryptographic 6-digit OTP codes sent via Resend API or Gmail SMTP with guaranteed delivery.

### Option A: Supabase Built-In Email Auth (Zero Server Setup)
1. Go to your **[Supabase Email Provider Settings](https://supabase.com/dashboard/project/douzzpvsfvvjlaiuwoce/auth/providers)**.
2. Ensure **Enable Email provider** is toggled **ON**.
3. Ensure **Confirm email** is enabled or disabled according to your policy (recommended: OFF for instant OTP login).
4. Go to **[Supabase URL Configuration](https://supabase.com/dashboard/project/douzzpvsfvvjlaiuwoce/auth/url-configuration)**:
   - **Site URL**: `https://namogpt.onrender.com`
   - **Redirect URLs**: Add `https://namogpt.onrender.com/**`, `http://localhost:5173/**`, and `http://localhost:3000/**`.

### Option B: Resend HTTPS API (Recommended for Cloud Hosting)
Cloud container hosts (Render, Vercel, Railway, Fly) can block traditional SMTP TCP ports (25/465/587). Resend uses port 443 HTTPS, ensuring 100% reliable delivery.

- **Required Variable**: `RESEND_API_KEY`
- **Sender Domain (Optional)**: If you have your own domain (e.g. `auth.namogpt.com`), add it to Resend to send from any address. Otherwise, NamoGPT auto-routes through `onboarding@resend.dev`.
- 👉 **[Get Resend API Key](https://resend.com/api-keys)**
- 👉 **[Verify Custom Domain on Resend](https://resend.com/domains)**

### Option C: Gmail App Password (SMTP Fallback)
If you prefer sending from your personal or business Gmail address:
- **Required Variables**:
  - `GMAIL_USER`: `yourname@gmail.com`
  - `GMAIL_APP_PASSWORD`: 16-character Google App Password (without spaces)
- 👉 **[Generate Google App Password](https://myaccount.google.com/apppasswords)**
  *(Note: Requires 2-Step Verification enabled on your Google account).*
